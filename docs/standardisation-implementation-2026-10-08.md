# College standardisation: implemented changes and remaining work

8 October 2026 — local release 2026.10.08.2 (updated 15 October 2026)

The tested foundation and the subsequent attainment/optional-AI release are implemented; five additive migrations (`20261008_001` through `20261013_001`) are applied to the local shared database. The latest release adds independent result imports, configurable grading/scaling/choice rules, protected marks revisions, department faculty sort ordering, parallel/shared-elective timetable conflict rules, and opt-in AI drafts. See the [current release details](deployment/attainment-ai-release-2026-10-08.md) and [production database migration guide](deployment/production-migration-2026-10-14.md) for present behaviour and limitations. This is a foundation release, not completion of the entire college digitalisation and AI programme. Existing disabled modules remain disabled. The original inspection document describes the starting state; this document describes the changes made afterwards.

## Update-by-update status

“Implemented” means the specific change described below is in the code and covered by the stated checks. It does not mean the entire surrounding module has completed college acceptance. “Partial” identifies further implementation, reconciliation, or acceptance work. “Awaiting input” identifies decisions or evidence that code cannot establish.
